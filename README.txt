AZURE + DATABRICKS LIVING MAP — PUBLISHING PACKAGE

This folder is ready for a static host such as GitHub Pages.

1. Upload every file in this folder to the root of a public repository.
2. In the repository, open Settings > Pages.
3. Publish from the repository's main branch and root folder.
4. Open the generated public URL once so the offline cache is installed.
5. Share that public URL in a LinkedIn post.

On supported Android browsers, use the Install button or the browser's
"Add to Home screen" command. The knowledge map and question engine remain
local; they do not send questions to an external service.
