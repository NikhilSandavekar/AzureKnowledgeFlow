# Azure + Databricks Living Map

**[Open the live app](https://nikhilsandavekar.github.io/AzureKnowledgeFlow/)**

An interactive learning map for Microsoft Azure, Azure Databricks, and Databricks concepts. Ask a question locally, inspect connected services, and trace architecture flows in execution order.

## Highlights

- 64 Azure and Databricks components connected through 134 relationships
- Local, private question answering with no external model call
- Straight-line architecture traces with a separate right-side explanation panel
- Unity Catalog, Microsoft Purview, ADLS, Delta Lake, Lakeflow, streaming, governance, networking, ML and AI coverage
- Installable Progressive Web App with offline caching
- Mobile-friendly touch controls and sharing support
- Additional guidance derived from the Packt *Data Engineering with Azure Databricks* examples

## Install on Android

Open the live app in Chrome, then choose **Install app** or **Add to Home screen**. Open it once while online so the app and knowledge map are cached for offline use.

This is an independent educational project and is not an official Microsoft or Databricks product.
